# Sky Rush ゲーム仕様書

- 対象バージョン: v1.1
- 更新日: 2026-09-16
- 本文書の基準: 現在のソースコード

## 1. ゲーム概要

Sky Rushは、空中に浮かぶ足場をジャンプで登り、頂上のゴールを目指すブラウザ向けオンラインアクションゲームです。最大20人のプレイヤーとCPUが同じコースに参加し、押し合いや足場ギミックを乗り越えて順位を競います。

対応端末:

- PCブラウザ
- スマートフォンブラウザ（縦持ち前提）

## 2. 基本フロー

1. プレイヤー名とパスコードを入力してログインする。
2. 既存の部屋へ参加するか、新しい部屋を作成する。
3. 部屋作成者がゲームモード、難易度、ステージ、最大人数を設定する。
4. 必要に応じて、部屋専用の入室パスコードを設定する。
5. 待機画面でチームまたはプレイヤーカラーを選択する。
6. ホストが開始すると、不足人数がCPUで補充される。
7. 5秒のカウントダウン後にレースが始まる。
8. 人間プレイヤー全員がゴールまたはリタイアするか、制限時間に達すると結果を表示する。

## 3. ログイン

| 項目 | 仕様 |
| --- | --- |
| プレイヤー名 | 必須、最大16文字 |
| パスコード | 必須、現在はサーバー固定値 |
| ブラウザ保存 | 入力欄は通常のパスワード欄として扱わず、パスワード生成・保存を促しにくい設定 |
| 再接続識別子 | `sessionStorage`へ保存し、同じタブの通信復旧に使用 |

## 4. 部屋

| 項目 | 仕様 |
| --- | --- |
| 最大人数 | 出走者2～20人。観戦者は別枠で最大10人 |
| 初期選択 | 5人 |
| ホスト | 部屋作成者。切断時は接続中の人間プレイヤーへ移管 |
| CPU補充 | 開始時に最大人数まで自動補充 |
| 途中参加 | 開始済みの部屋には参加不可 |
| 状態保存 | サーバーメモリ内。サーバー再起動で消去 |
| 入室パスコード | 部屋ごとに設定有無を選択。設定時は4桁の数字 |

ホストは待機中の人間プレイヤーを部屋から退出させられます。試合中は任意の時点で試合を終了でき、終了後は同じ部屋設定と人間メンバーを維持したまま再戦待機へ戻せます。

パスコード付きの部屋はロビーに「パスコード」と表示します。入力値は部屋一覧やルーム状態へ配信せず、サーバーではソルト付きハッシュだけを保持します。

CPUは次の2種類をほぼ半数ずつ配置します。

| 種類 | 表示例 | 行動 |
| --- | --- | --- |
| 弱CPU | `CPU 1 弱` | 近くの上段を狙う従来型AI。足場の未来状態は予測しない |
| 強CPU | `CPU 2 強` | 2段先のルート、離陸点、着地点、移動床、消える床を予測するAI |

CPUのキャラクターカラーはグレーです。

## 5. ゲームモード

### 5.1 バトルロワイヤル登山

- 個人順位を競うモードです。
- プレイヤーは任意のキャラクターカラーを選択できます。
- 他プレイヤーと接触すると押し合いが発生します。
- 最初にゴールしたプレイヤーがいても試合は終了しません。

### 5.2 チーム登山

- 1～4のチームを選択して協力するモードです。
- 人間プレイヤーは開始前にチームを変更できます。
- 同じチームのキャラクターはチームカラーで統一されます。
- 味方の頭上に着地し、踏み台として利用できます。
- 味方の上からジャンプした場合は通常より強いジャンプ補正がかかります。
- 協力エリアと高壁を含む専用ステージを使用します。

## 6. 難易度

| 難易度 | 足場表示 | ゲーム内性能 |
| --- | --- | --- |
| ノーマル (`normal`) | 足場種類ごとのカラー表示 | 標準 |
| ハード (`hard`) | ゴール以外の足場をグレー表示 | ノーマルと同一 |

現時点の難易度は、足場種類を色で判別できるかどうかを変更する視認性ルールです。物理性能、足場配置、制限時間は変化しません。

## 7. 操作

### 7.1 PC

| 操作 | キー |
| --- | --- |
| 左移動 | `A` または左矢印 |
| 右移動 | `D` または右矢印 |
| ジャンプ | `Space`を押して離す |
| 溜めジャンプ | 接地中に`Space`を長押しして離す |

### 7.2 スマートフォン

| 操作 | ジェスチャー |
| --- | --- |
| ジャンプ | 画面をタップして離す |
| 溜めジャンプ | 接地中に長押しして離す |
| 左右移動 | 触れた位置から左右へドラッグ |

- 横移動の判定には22pxのデッドゾーンがあります。
- ジャンプチャージは接地中のみ蓄積します。
- 最大チャージ時間は650msです。
- カウントダウン中はジャンプ入力を受け付けません。

## 8. キャラクター

- キャラクター名: プニラッシュ
- 通常、ジャンプ、落下、着地、チャージ、押し出しの状態に応じて表情と変形が変わります。
- チャージ中は横につぶれ、ジャンプ中は縦に伸びます。
- 着地時は一時的につぶれるアニメーションを表示します。
- 押し合い発生時は短いエフェクトを表示します。

### 8.1 効果音

- ジャンプ、着地、ゴール、試合終了時に短い効果音を再生します。
- 効果音はWeb Audio APIで生成し、音声ファイルの追加ダウンロードは行いません。
- ジャンプと着地の音は、操作中の自分のキャラクターに対してだけ再生します。
- ブラウザの自動再生制限に対応するため、最初のジャンプ操作または音声オン操作で音声を有効化します。
- 上部の音声切替でオン・オフを変更でき、設定はブラウザへ保存します。

## 9. 足場

| 種類 | ノーマル時の色 | 動作 |
| --- | --- | --- |
| 通常床 | 黄・緑・水色を配置順に切替 | 固定された基本足場 |
| 伸縮床 | ピンク | 横幅が一定周期で伸縮 |
| 消える床 | 紫 | 表示時間と非表示時間を周期的に繰り返す |
| 移動床 | 水色 | 指定された左右範囲を往復。乗っているキャラクターも運ぶ |
| ゴール | 黄色 | 到達するとゴール扱い |

自動ジャンプ床は使用しません。

## 10. ステージ

### 10.1 バトルロワイヤル登山

| ID | 表示名 | 高度 | 目安 | 制限時間 | 特徴 |
| --- | --- | ---: | --- | ---: | --- |
| `battle_01_garden` | はじまりの空庭 | 約2000m | 初級 | 3分 | 広めの足場、複数ルート、基本ギミック |
| `battle_03_cloud_jumble` | 雲間ジャンブル | 約5000m | 初中級 | 6分 | 消える床が多く、移動床で左右へ揺さぶる |
| `battle_07_cup_qualifier` | スカイラッシュ杯 予選 | 約5000m | 中上級 | 6分 | 20人向け。序盤の分散から終盤の競争へ収束 |
| `battle_10_everest_rush` | エベレスト・ラッシュ | 約8000m | 超上級 | 10分 | 短い消える床中心。高所ほどリカバリーが難しい |

| ID | 表示名 | 高度 | 目安 | 制限時間 | 特徴 |
| --- | --- | ---: | --- | ---: | --- |

## 11. コース作成ルール

- 全参加者が乗れるスタート床を1枚設置する。
- スタート床より下に足場を設置しない。
- 序盤は複数ルートを許容し、終盤は1ルートへ収束させる。
- 最大チャージジャンプを含め、スタートからゴールまで到達経路を持たせる。
- 意味のない小さな高低差の足場を連続させない。
- 一部に溜めジャンプが必要な区間を設ける。
- 上段の裏へ頭をぶつける配置は、横から回り込む経路または消えるタイミングによる通過経路を確保する。
- 「短い下段が長い上段の真下にあり、上段へ抜ける方法がない」配置は禁止する。
- 移動床は左端・中央・右端の各状態でも、コース全体の到達性を失わない範囲に置く。
- ゴール周辺には進入を妨げる足場を置かない。

## 12. レース進行

### 12.1 カウントダウン

- 全ステージ一律5秒です。
- カウントダウン終了までは物理更新とジャンプを開始しません。

### 12.2 落下と復帰

- スタート高度より一定距離下へ落ちたプレイヤーはスタート地点へ戻されます。
- 順位や高度は現在位置を基準に更新します。

### 12.3 リタイア

- カウントダウン終了後、出走中の人間プレイヤーは確認操作を経てリタイアできます。
- リタイアはゴールとして扱わず、以後の入力、物理、接触判定、キャラクター描画を停止します。
- 試合が続いている場合は観戦モードへ移り、残っている出走者を手動で切り替えられます。
- リザルトでは未リタイアの出走者より下位に並び、「リタイア」と表示します。

### 12.4 ゴールと終了条件

- ゴール高度へ到達したプレイヤーは操作を終了します。
- 人間プレイヤーが全員ゴールまたはリタイアすると試合終了です。
- 人間プレイヤーが残っていても、ステージの制限時間に達すると試合終了です。
- 人間の出走者がいる通常試合では、CPUのゴール状況を終了条件に含めません。人間の出走者が0人の場合のみ、CPU全員のゴールで終了します。
- 最終順位はゴール順、未ゴール者の終了時高度、リタイア者の順で並べます。

### 12.5 観戦モード

- ゴール済みの人間プレイヤーは、試合終了まで観戦モードへ移行します。
- 接続中かつ未ゴール・未リタイアのプレイヤーを高度順に観戦できます。
- 「前へ」「次へ」で観戦対象を切り替えます。
- 待機中は各プレイヤーが「出走する」「観戦する」を選択できます。
- 最大人数は出走枠を表し、観戦者は出走枠を消費しません。
- ホストが試合開始を押した時点で役割を固定し、空いている出走枠をCPUで補充します。
- 出走する人間が0人の場合は、設定した最大人数ぶんのCPUだけで試合を開始します。
- 観戦者は接触判定、順位、リザルトから除外されます。

### 12.6 大会中継モード

- ホスト端末で試合中に切り替えられます。
- 上位8人のライブ順位を表示します。
- 注目中のプレイヤーを順位表上で強調します。
- 「前へ」「次へ」で注目選手を手動変更できます。
- 中継モードはホスト端末の表示だけを変更し、他プレイヤーの画面や試合状態には影響しません。
- 観戦者を選択したホストが試合を開始すると、大会中継モードが自動的に有効になります。
- 出走者を選択したホストには中継モード操作を表示せず、試合終了操作だけを表示します。

## 13. UI表示

- 操作・状態ラベルは日本語で表示する
- UI本文はGoogle Fontsから読み込む`Noto Sans JP`を使用する。ブランドロゴは専用書体を使用する
- 接続状態: 接続中、オンライン、オフライン
- 上部ステータスバーは高さ40pxで固定し、通常時は部屋・ステージ・難易度、通知中は同じ領域に情報・注意・エラーを表示する
- 通知の出入りで下の画面が移動しない。長文は領域内で省略する
- 部屋名、ステージ、難易度
- 順位、残り時間、高度マップ
- ジャンプチャージゲージ
- 操作中の自分には、黄色の足元リング、頭上マーカー、`あなた / プレイヤー名`ラベルを表示する
- 12人以上の試合では、他プレイヤーの名前を小さく半透明にして自分の表示を優先する
- ラストスパート表示
- ゴール時の`GOAL`、順位、リング演出
- ルール画面
- 結果順位
- リザルト上位3名の表彰表示、紙吹雪、順位表の順次表示
- ホスト専用の試合結果CSVダウンロード（ブラウザ生成、UTF-8 BOM付き、サーバー保存なし）
- CSVには部屋、ステージ、難易度、開始・終了日時、終了理由、ビルドコミット、順位、名前、チーム、結果、ゴール時間、高度を含める
- ログイン画面のv1.1およびビルドコミット

## 14. 通信断

- 通信断を検知すると再接続中の表示へ切り替えます。
- 試合中に切断した人間プレイヤーは、最大2分間サーバーに保持されます。
- 同一セッションで再接続すると、位置と試合状態を引き継ぎます。
- 切断中は入力を停止します。

## 15. 現在の制限事項

- 1試合の上限は20人です。200人が同時に1コースへ参加する仕様ではありません。
- 部屋と試合状態は単一サーバープロセスのメモリに保存されます。
- ECSを複数タスクに増やす場合は、スティッキーセッションまたは共有状態管理が必要です。
- パスコードは固定値で、本格的なユーザー認証ではありません。
- プレイ履歴・監査ログ・戦績保存は未実装です。
- ハードは視認性のみを変更し、物理的な難易度は変更しません。
