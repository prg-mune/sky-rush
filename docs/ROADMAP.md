# Sky Rush ロードマップ

- 更新日: 2026-09-15
- 対象: v1.1以降

## 1. 目的

Sky Rushを200人規模の社内ゲーム大会で使用できるコンテンツへ育てる。1試合は最大20人を維持し、複数試合の進行、観戦、結果集計を段階的に整備する。

## 3. 推奨実施順

1. サウンドとチュートリアル
2. 部屋のパスコード化
3. 協力プレイのブラッシュアップ
4. ホスト操作と大会中継画面
5. ログ・戦績保存
6. 大会モード最小版
7. 独自ドメインとLP
8. ティザー動画

順番は固定ではなく、大会日程と検証結果に応じて変更する。現在は4を先行している。

## 4. ホスト操作・大会中継画面

最初の実装範囲:

- 待機中プレイヤーの退出操作
- 進行中試合の終了操作
- 同じ部屋設定での再戦準備
- 中継モードの切り替え
- 上位順位の常時表示
- 手動での観戦対象切り替え
- 待機中の出走・観戦選択と観戦者向けカメラ

上記はv1.1開発版で実装済み。待機中に各自が出走・観戦を選び、開始時に役割を固定して空き枠をCPUで補充する。出走者が0人なら部屋の最大人数ぶんのCPUだけで試合を開始する。観戦を選んだホストは大会中継モードへ自動移行する。

後続候補:

- CPUの強弱比率設定
- 制限時間変更
- 観戦専用参加者
- 複数ルームを一覧管理する運営コンソール
- 全ルーム一斉開始

## 5. 大会モード案

### フェーズ1: 大会作成

- 大会名
- 参加者一覧
- 使用ステージ
- 1組の人数
- 各ラウンドの通過人数

### フェーズ2: 組み分け

- 参加者の自動分割
- ルームとパスコードの発行
- 欠席者の差し替え

### フェーズ3: 試合進行

- 各ルームの参加状況
- 開始・終了状態
- 通信状態
- 運営者による進行操作

### フェーズ4: 勝ち上がり

- 予選、準決勝、決勝
- 上位者の自動選出
- 同着や失格の手動補正

### フェーズ5: 総合結果

- 最終順位
- ラウンド別結果
- CSV出力
- 表彰画面

## 6. 公開・告知案

- LPとゲームを`www`またはルートドメイン、`play`サブドメインに分離する。
- ティザー動画は15～30秒を目安にする。
- 動画では20人スタート、押し合い、特殊床、ラストスパート、ゴールを短く見せる。
- LPには対応端末、操作方法、開催日時、参加方法、注意事項を掲載する。
